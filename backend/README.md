# Backend — Laravel 12 API

This folder contains the REST API of the Ecommerce project.

Setup, configuration, demo accounts, deployment and the API reference are documented in the
[main README](../README.md).

Common commands:

```bash
composer install
php artisan migrate --seed     # create + fill the database with demo data
php artisan serve              # http://localhost:8000
php artisan test               # unit + feature tests
```
